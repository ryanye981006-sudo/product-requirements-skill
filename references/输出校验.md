# 输出校验

每次交付检查最终版本。校验过程保留在工作记录，交付说明只汇报结果及具体待确认项，需求正文保持面向研发的内容。

## 内容检查

输入包括本次用户要求与纠正、需求依据、相关现有规则、风格参考和最终 Markdown。明确每份材料的用途，避免把历史范例当作本次需求。

1. 从依据逐项核对正文，检查新增、修改、删除及必要边界是否齐全。再从正文逐项追溯依据，找出自行新增的功能、字段、指标和参数。
2. 对照输入核实数字、单位、范围、默认值、排序顺序、状态、权限、去重、异常、返回字段和同步规则。已删除、划线或标注暂缓的方案不得恢复为确定需求。
3. 检查与相关现有规则及文内其他条目的冲突。仅在已查阅范围内下结论，缺少现有资料时说明无法核实的具体点。
4. 按 `文风.md` 检查重复价值描述、同义复述、空泛表达、无依据扩展的常规交互，以及为压缩篇幅遗漏的核心逻辑。必要的权限、数据同步、失败处理等仍须保留。
5. 待定参数随对应规则标注。确认建议尚未混入正式需求。检查标题、文件名、正文、示例是否围绕最终采用的需求。

已授权撰写或改稿时，修复有依据的问题后复核受影响条目。纯转换时保持源文，内容问题列入简短提示，继续完成忠实转换。缺少业务决策时提问或标待确认，避免反复等待全部参数确认才制作草稿。

## 独立复核

有子 Agent 能力时，可委派一次独立内容复核，复杂或多来源需求优先采用。提交本次要求、依据、相关现有规则、最终 Markdown、所选格式的输出路径、`文风.md` 和本文件。子 Agent 读取实际文件，只返回有证据的问题，包含位置、原句、依据、影响及最小修改建议，标明检查覆盖范围。主 Agent 核实后修订，并重新检查受影响内容与导出文件。最终决定由主 Agent 负责。

可使用以下委派任务。

> 复核所附需求和导出文件。逐项检查需求覆盖、范围依据、规则一致性、文风及转换保真。指出具体位置和来源证据，区分缺失依据与已证实冲突。保留核心规则，不补充产品功能。不要直接修改文件或操作线上文档。输出问题及检查范围，没有证据的问题不列出。

没有子 Agent 时，主 Agent 用同一清单重新读取成品完成复核。语义与文风检查由 Agent 判断，不能用字数阈值或关键词黑名单替代。

## 格式选择与 lake 检查

1. 根据当前任务意图核对交付文件。导入语雀对应 `.lake`，复制到语雀对应带复制按钮的 HTML，两种都要时同时交付。只写 PRD 且未指定格式时交付 Markdown。
2. `.lake` 按 `lake-format.md` 生成，运行 `scripts/validate_lake.py`。核对四个 meta、标题层级、唯一 ID、表格列数与宽度、空图例、ol 的共享 list、缩进和接续编号。脚本覆盖结构基础项，层级语义与编号接续由 Agent 对照底稿复核。
3. 逐格比对底稿与 lake 的内容，保留数字、条件、待定标记、加粗、链接和图例。文件应仅含需求内容。未支持的内容明确说明位置与影响。
4. 同时输出两种格式时，从同一最终底稿生成并交叉核对。任一格式改动正文后，同步更新底稿及另一格式，再复核。
5. 用户授权语雀导入实测时，执行 `yuque-paste.md` 中的导入步骤。静态检查通过只能报告本地结构检查通过。

## HTML 与复制检查

仅输出 HTML 时执行以下检查。两种格式同时交付时也执行。

1. 核对最终 Markdown 与 HTML 的表格数量、各表数据行数、每行列数、标题和行顺序，以及逐格正文。空白图例应占据原列，复制操作列不得混入内容。
2. 逐项检查数字、条件、否定词、待定标记、加粗、换行和列表层级。不能以总字数相近证明转换完整。
3. 转换前识别嵌套列表、跨行单元格、图片、链接、删除线、原始 HTML 等脚本未完整支持的语法。适配时保留条件从属关系、图片位置和暂缓状态，不能将嵌套编号简单拉平或让删除线内容变成现行需求。未解决的部分须说明具体位置及影响。
4. 打开本次生成的 HTML，点击真实复制按钮。每张表至少覆盖一行，另外覆盖存在的最长行、有序列表、加粗及空图例。检查复制成功、列数、列表编号、加粗和四种剪贴板类型。操作列不能进入复制数据。
5. `test_convert.py` 与 `test_copy.cjs` 验证转换器及合成样例，当前交付文件仍需独立检查。浏览器能力不可用时完成可执行的静态检查，说明实际按钮复制尚未验证。
6. 语雀内粘贴按 `yuque-paste.md` 执行。只有真实粘贴后的列、列表和加粗均核实，才能报告语雀实测通过。

## 交付结论

交付绝对路径链接及简短使用方法。说明内容检查结果，以及所交付格式的保真检查、结构检查与实际导入或复制测试结果，列出仍待确认或未验证的具体事项。根据实际执行情况报告自检或独立复核。已有内容缺口的草稿可交付，标明缺口，避免笼统声称全部通过。
