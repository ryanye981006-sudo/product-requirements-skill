# 语雀实测与兼容边界

只在用户要求测试或已有明确测试授权时操作语雀。登录、实例选择、借用及清理按所用浏览器 Skill 执行，不绑定作者的账号、地址、端口或实例 ID。

## HTML 粘贴验证

1. 打开用户指定文档，进入编辑态。确认测试行为空，记录原表头、列数和行数。不能覆盖正文；没有可用区域时先提供本地结果。
2. 打开生成 HTML，实际点击【复制本行】，按钮须在视口内。直接执行复制函数或只构造 payload 不等于真实复制测试。
3. 语雀目标行第一格，真实 `Ctrl+V`。确认各列独立、空图例仍为空、操作按钮不出现；描述编号有列表缩进，DOM 为 `ne-oli`；加粗内容有原生标记。
4. 编辑器异步更新，短暂等待后检查一次，不反复写入。大文档可能虚拟滚动，用实际滚轮加载目标表格，并重新读取元素。
5. 选中整条测试行清空，确认表头、行数保留且内容消失。等待自动保存后重进编辑页核对清理结果，关闭测试会话。

若扩展不允许文件地址，可把单份 HTML 放入单独临时目录，仅在 `127.0.0.1` 提供预览。不能把整个项目或下载目录作为 HTTP 根目录。结束后停止临时服务。

## 关键格式

原生片段为 `fragment → table → tr → td`。`td.attrs.col` 标识列；表格记录 `rowCount`、`colCount`、`colWidths`。操作列仅供本地 UI 使用。

有序列表是相邻的 `oli`，不是 `p` 加字面序号：

```json
{
  "type": "element", "name": "oli", "id": "unique-item-id",
  "attrs": {
    "indexType": 0, "list": "shared-list-id", "fid": "shared-list-family-id",
    "parentIndex": [], "index": 0, "indexStyle": {}
  },
  "children": [
    {"type": "text", "name": "#text", "id": "unique-text-id", "attrs": {"bold": true}, "data": "重点规则"}
  ]
}
```

第二项 `index` 为 1，依此递增。`text/html` 含 `ne-clipboard` 编码片段及普通表格；`text/lake` 提供 HTML，`text/ne-inode` 提供原生 JSON。模板写入四种 MIME 类型。未观察到的节点格式不要凭空补充。

## 故障定位

- 整行进一格：检查真实复制是否写入两个原生类型，以及目标是否为第一格。仅有标准 HTML / TSV 不能证明网格类型已写入。
- 列正常而列表失效：检查 `oli` 和共享列表标识；不要回退为 `p` 加 `1.`。
- 加粗失效：检查源 `strong` 和文本 `attrs.bold`，不要把 `**` 当正文。
- 复制失败：检查 Chromium、页面焦点及真实点击。保留失败提示，不能显示成功。
- 平台不兼容：停止测试、保留本地 HTML，报告实际结果与限制，不反复试写正文。

原生结构来自语雀复制样本，2026-10-12 在 Chromium 中经 BrowserSkill 真实 `Ctrl+V` 验证了三列、列表、加粗及清理保存。该剪贴板不是公开稳定 API，平台或浏览器更新后应重新实测。

## lake 导入验证

用户要求或已授权导入实测时，使用用户指定的知识库及临时测试文档位置。文件通过当前界面的导入入口上传，记录生成的测试文档，避免覆盖已有正文。导入位置不明确时先询问，期间完成本地结构和内容校验。

导入完成后检查标题层级、各表行列、空图例、编号缩进和接续、加粗、图片及待定标记，并对照底稿核实内容。存在解析或格式问题时定位并修复本地文件后再测。测试结束按授权清理新建的测试文档，仅清理本次创建的内容。

若当前界面缺少 lake 导入入口或拒绝文件，报告具体情况及已通过的本地检查，保留生成文件供排查。报告仅描述实际验证结果。
